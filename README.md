# PaperKito.github.io

Account-level GitHub Pages site: <https://paperkito.github.io/>

Not tied to any single project — sponsor links stay valid no matter which
repository they are linked from.

| Path         | Purpose                          |
| ------------ | -------------------------------- |
| `/sponsor/`  | Sponsor landing page             |

## Deploy

Settings → Pages → Build and deployment → Source: `Deploy from a branch`
→ Branch `main`, Folder `/ (root)`.

The QR images are referenced by relative path from `sponsor/`, so replacing a
code needs no rebuild anywhere else.
